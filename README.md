- 首页保持轻量 HTML 页面壳，不再内嵌完整岗位池。
- 启动阶段优先使用 `YINGZHUAN_JOBS` 精选岗位快速进入正式看板。

- Eligibility Gate、Career Fit、Capability Score、S/A/B 与评分逻辑由现有核心模块保持不变。
- 版本化岗位快照使用长期 immutable 缓存。
