## 收窄规则

### 行业：只保留四类，其余全部剔除

| 保留 | 理由 |
|---|---|
| 智能硬件 / 消费电子出海 | 制造业出海是结构性主线，她的安斯泰莫经历正面命中 |
| 汽车 / 新能源出海 | 同上，且与中车海外经历同构 |
| 品牌方跨境（自营，非代运营） | 积累的是品牌与市场能力，不是平台操作技能 |
| 央国企国际业务 / 外企 | 作为稳定保底，数量控制在个位数 |

**已整体剔除的行业**：保险（中国人寿130、太平101、人保48、泰康13）、教培（新东方68）、审计咨询（德勤124）、国内互联网平台（得物73、阿里32、字节31、快手28、美团25、腾讯24、拼多多19、小红书6 等）、游戏、本地生活、国内物流。

合计剔除约 **900+ 条**。这些岗位不是"投不进"，而是投进去以后第3年会把她锁进错误的人才池。

### 职能：只保留英语是生产资料的岗位

**保留**：海外市场 / GTM / 产品营销（海外）/ 海外运营 / 跨境电商运营（品牌方）/ 海外商务 / 国际供应链与物流 / 海外管培生通道

**剔除**：翻译、本地化专员、外贸跟单、行政文员、客服、渠道销售、HR、财务审计法务、技术研发测试、EHS/安全、生产制造、采购执行、国内线下渠道

### 额外收窄条件

1. **标题必须带海外信号**（海外/国际/跨境/全球/GTM/外贸/亚马逊/TikTok/独立站/欧美）——或公司本身是纯出海企业（拓竹、图拉斯、安克、致欧、傲基、SHEIN、正浩、影石、传音、扬腾、Babycare、万兴）
2. **管培生通道优先**：清单中 26 条为管培/培训生通道，用掉了她985的院校筛选优势
3. **同公司同类岗位去重**，每家公司上限 4 条，避免把名额堆在一家
4. **fit < 65 全部剔除**

### 使用建议

- 总量 60 条，落在建议的 60–75 区间内
- **冲刺 21 条必须逐份定制**，这部分决定上限
- 标 ⚠ 长期派驻/驻外的 2 条，投之前先想清楚：驻外的价值窗口有限，只有把个人能力和客户关系沉淀下来才值钱，"在国外待过"本身不值钱
- 标 ⚠ 关键技能需补足的，JD 里提到了数据分析/SQL 类要求（非硬门槛），面试前准备好 Excel/数据的话术
- 清单里没有任何一条纯翻译、跟单或行政岗——这是刻意的
